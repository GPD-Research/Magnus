Magnus Gore Geometry Sketch Tool

Draw the exact fog-line / shoulder-edge / gore-area relationships you mean, point by point on a grid, then export a JSON (and/or SVG) file for Copilot to analyze as real coordinate data instead of another verbal description.

  1. Pick a scene tab: On-ramp, Off-ramp, or On-ramp + Off-ramp.
  2. Pick a line type in the right panel (its color/style shows on the grid). Draw lines in the direction of travel.
  3. Click grid points on the canvas to add straight segments. Click Finish line when that line is done, then pick the next type.
  4. Repeat for every line relevant to this scene, then switch tabs and repeat for the others.
  5. Click Download JSON (and optionally Download SVG) and send the file back.
